# PASSAR NO ENEM — versão independente

Versão estática e independente para estudo imediato. Não depende de Lovable, Base44, Supabase, autenticação ou créditos de IA para funcionar.

## Incluído
- 45 questões oficiais de Matemática do ENEM 2025 (136–180), com gabarito oficial.
- Questão 174 marcada como anulada.
- Missão do dia determinística.
- Registro local de tentativas e hipóteses de erro.
- Palácio do Conhecimento com nós de Matemática e pré-requisitos.
- Painel de progresso.
- Funciona offline depois de abrir os arquivos.

## Deploy
Hospedagem estática: basta servir esta pasta.
